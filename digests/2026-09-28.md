4. 真正值得跟踪的是它们共同依赖的那条证据链断了：CONCAT（arXiv:2605.29612）被作者主动撤稿，理由是重复运行评测可能存在 prompt 跨运行串扰、影响了报告结果。以它作证据的几篇合成稿因此删掉章节、把结论降级为「未验证假设」——这条撤稿比任何一篇综述都更有信息量。
5. 唯一一篇由真实研究者署名的「Vibe coding an online ELAN viewer」（Max Planck 心理语言学研究所）是 LLM 辅助编程的一手经验报告，与博弈和多智能体战略交互无关，属检索误命中；不过「一次只提一个需求」「用 skills 与 workspace rules 缓解长程上下文丢失」「简单模型做默认、复杂模型留给设计与调试」几条，对跑 agentic 流水线有直接参考价值。
