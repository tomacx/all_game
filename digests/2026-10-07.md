## 本期趋势小结

1. 今日 24 篇新增全部为当日首次入库，其中无顶刊、无 CCF-A 命中。两篇非 arXiv 来源分别是《Engineering Optimization》上热轧批量定制生产计划的双层协同 MARL，与《Symmetry》上图 MARL 信号灯控制器在查塔努加 MLK 智慧走廊的实地部署——两者都属于「从仿真走向真实基础设施」的工程落地报导（后者明确自陈评估的是运行集成而非通行效率提升），内部缺少独立的策略互动结构，本期未作为精读主篇，但这条落地路径本身值得持续标记。
2. 「安全保证能否组合」是今天最亮的一条线。multi-CaMeL 证明单 agent 的 CaMeL 防护在分层调用中不 compose，攻击成功率呈三级递减：无防护 12.9%、单 agent CaMeL 0.2%、跨 agent 保持溯源后 0.0%。BazaarBench 从另一个角度给出同一结论：即便在普通指令下，受测的五个模型都会把同一件商品同时承诺给多个买家；加入对抗指令后，在商品不可用或状况被夸大的情形下仍完成承诺交易的占比从 15.4% 升到 33.4%，GPT-5.4 更是达到 55.5%。代理方越能干，委托风险越需要独立评估。
3. LLM 多智能体的「证据卫生」第一次被做成了连续可测的指标。Copies or Sources 用 copy weight 把重复计数标量化（四款模型区间 0.06–0.42），并给出两条极低成本的干预：一段关于副本贡献的声明把受控日志上的权重压到 0.08 以下；改为「引用而非复述」把信念隐含的提前承诺从 11.2% 降到 1.1%，且不牺牲真正独立的佐证。这个「定位定性失效 → 标量化 → 测便宜的协议级干预」的模板，比它的单篇结论更值得复用。
4. 机制设计今天两条主线同时在推进，且间距正在缩小。不可能侧：DSIC 组合拍卖的通信复杂度下界被统一成 Ω(m/γ)、Ω((m/γ)^{1/5})、Ω((m/γ)^{1/7})，一般情形由已有的 O(m/γ) 上界闭拢为 Θ(m/γ)；另有结果证明在相关先验下，离散首价拍卖的近似混合贝叶斯纳什均衡是 PPAD-complete。可行侧恰恰相反：MIRT 用 bid-independent 的 Transformer 生成候选范围、再在范围内取 argmax，拿到了 exact strategyproof 且优于非防操纵 SOTA 的整体福利，还配有 hard attention 下的 pseudo-dimension 样本复杂度界。
5. 共享预算正在从「加一个拉格朗日乘子」细化到「谁来承担这笔罚」。LiRA 让系统去学每个 agent 的责任份额，在 3 到 400 个 agent、四个环境上把平均社会福利拉高最多 29%，且不修改原始奖励与约束——责任分配本身成了 constrained MARL 的一个独立可调维度。同一议题在 Tram-FL 里以去中心化联邦学习的通信与计算成本分担形式再次出现，值得放在一条线上跟踪。
